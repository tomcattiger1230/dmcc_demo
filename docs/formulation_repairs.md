# DMCC 演示的方程与入口修补

基于 main 的 `e56d160dc85b406c7557ac6dd8a25d5c2590c214`，修复此前检查发现的问题。
当前模型仍为带机械臂的 Euler 坐标 DMCC；它不声称已经转换为纯四旋翼 SO(3)-LGVI。

## 时间与坐标

原 `dEL` 以总时间 Tn 为输入，内部已使用 Tn/(N-1)，但调用又传 self.dt。
修补为 `dEL(Tn, ...)`，离散力仍使用 self.dt。回归检查直接评估完整 NLP
的内部平移方程：N=11、T=1 s、1 m/s^2 加速度应给出 -mass*0.1，
从而检测真实组装方程中再次除以 N-1 的错误。

`initialization_formulation(dynamics_convention='euler_consistent')` 同时修正：

- 离散配置差分传给 L 的量是真正 Euler 坐标导数，而不是机体系角速度近似。
- 旋翼机体系力矩映射到 Euler 广义力为 T(q).T*tau_body。
- alpha 是相对机体关节角，内部电机虚功仅 tau_m*d(alpha)，不重复施加共同旋转力矩。
- 离散力使用端点梯形虚功，各区间向其端点贡献 h/2*Q(q_i,u_i)。

默认类 API 仍为 `legacy`、`regularized`，保留历史研究的旋转/力矩/离散力约定。
默认 CLI 显式选择 `euler_consistent`、`minimum_time`。
后者目标只有 Tn，取消输入/路径惩罚和强制悬停输入边界。
时间步长及约束修补在两种模式均生效。完整原实现可以在原提交查看。

物理修正模式拒绝不符合主惯量三角不等式的机体惯量。
固定接触示例明确沿用赛车示例已经提供的 `[0.01558,0.01523,0.01926] kg m^2`，
替代原接触示例误用的非法默认值；这是示例配置变更，不能自动推广为另一机体的辨识参数。
原符号推导的电机力矩常数仍为 0.013、机体 frame_size 仍为 0.33 m。

## 航点与接触

航点约束使用运行时 W_ref、平方距离、平方容差变量。
默认 radius=0.05 m，对应 tolerance 上界 0.0025 m^2。
进度下降在节点 i+1 认证，包含终端；加入 mu>=0、lambda_j<=lambda_(j+1)。
CLI 对中间航点加入可配置的离散通过速度条件，终端仍可静止。

接触距离/相对速度采用 `sqrt(sumsqr(error)+eps^2)-eps`，默认 eps=1e-6，
在零误差处值为零、导数有限。运动目标的航向使用几何方向误差，
静止目标的速度方向条件为零；不会计算 atan2(0,0)，也不会把反向平行误判为一致。
contact_speed_tolerance 的界直接为 m/s；heading_tolerance 的界使用平方方向误差，
小角度下与 rad^2 一致，避免把线性速度范数用平方速度单位约束。
接触 progress 初值符合 kappa[k+1]-kappa[k]+epsilon[k]=0，支持非整数 kappa0，
节点不足时明确报错，避免原 while 循环越界。

互补约束仍是 MPCC，平方/平滑距离不消除互补退化，不能保证任意初值收敛。
离散区间通过速度也不构成连续时间严格不停留证明。

## 参考、边界与运行

参考数组与初值分离，不再覆盖终端速度；pack_parameters() 统一 (M,14) 行状态打包。
初值使用 NumPy 数值运算，3D 距离用于分配网格，重合点方向除零得到保护。
默认/显式节点数保持一致；切换节点严格递增，缺少平均速度时也能初始化。
共享 bounds builder 用同一个总质量和重力计算悬停及旋翼限制，匹配实际分支维度。
7 自由度模型不能靠 has_manipulator=False 去除机械臂，误用会明确报错。

数值旋转计算使用 CasADi concatenation，legacy 速度导出通过符号函数计算，
支持新 NumPy/CasADi 的 DM 类型。完整状态平均速度的平移索引纠正为位置增量。
3D scatter 参数和结果目录创建也得到修复。
求解后检查 success、所有数值有限和完整变量/约束界，违反超过 1e-5 时拒绝导出。
